# Action Timeline Editor

画像を含まないローカルのLeRobotデータセット（v2.1 / v3）のActionを編集するWebツールです。
Python標準HTTPサーバーとNumPy / PyArrowを使用し、ブラウザー側の依存ライブラリーやCDNは不要です。

リポジトリのルートから起動します。

```bash
.venv/bin/python tools/action_editor/server.py --dataset datasets/iloha-best
```

ブラウザーで http://127.0.0.1:8765 を開きます。ポート変更は `--port 8766`。
別環境の場合は `python -m pip install numpy pyarrow` で依存を導入してください。

- デフォルトはEpisode 0。存在しなければ最小番号を表示します。タブでエピソードを切り替えます。
- Actionの各次元を独立したレーンとして表示します。灰色は編集前Action、橙色は同じ次元番号のobservation.stateです。
- 波形をドラッグして範囲選択します。Shift付きドラッグでレーンを追加できます。チェックボックスで複数レーンを同時編集できます。
- フレーム指定は `[開始, 終了)`。終了フレームは含みません。表示上部に秒も表示します。
- 「コピー」は選択区間を配置先に上書きします。「移動」は元区間を前後の値で線形補間してから配置先に上書きします。重複範囲への移動にも対応します。
- ドラッグ操作を「移動」「コピー」に切り替えると、ハイライト内からドラッグしてタイミングを変更できます。
- 「伸縮して配置」は線形補間で指定フレーム数にリサンプルし、元区間を補間して配置先に上書きします。
- 端からはみ出す操作はエラーになります。表示開始・終了で任意区間を拡大できます。
- Undo / Redoは全エピソード共通で最大50操作。対象のエピソードに自動で切り替わります。
- 「データセットを保存」で未使用の別ディレクトリに全エピソードを保存します。元ファイルは変更せず、既存ディレクトリへの上書きもしません。
- ParquetのAction列のみ変更し、グローバルおよびエピソード別のAction統計（分位点を含む）を再計算します。その他の列・メタデータは保持します。

フレーム数、timestamp、observation.stateは変更しません。ActionだけをずらすとStateとの対応も変わるため、学習用途に合わせて編集してください。境界の動作を自動で滑らかにする機能はありません。

サーバー終了で未保存の編集は失われます。単一ユーザー向けで、開いたブラウザー間で編集状態を共有します。全データと最大50操作の履歴をメモリに読み込みます。大規模データセットではメモリ使用量に注意してください。
