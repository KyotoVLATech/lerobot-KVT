# Iloha データセットの関節編集

リポジトリ直下で起動します。

```sh
uv run iloha_trajectory_web.py
```

http://127.0.0.1:8765/editor.html を開きます。既存の軌道接続ページの「関節角度・データセット編集」からも移動できます。

1. `iloha-common` とエピソードを読み込み、再生バーで腕が伸びる時刻を選択します。
2. 「現在の時刻を使う」を押し、左腕 `joint_1` または `joint_2`、幅σ（秒）、加算角度（度）を設定します。負の角度で減算できます。
3. 灰色の元姿勢と青色の編集姿勢、距離と角度グラフを比較します。入力中の調整も反映されます。到達距離は姿勢によって増減するため、数値を確認しながら符号と大きさを調整してください。
4. 「この調整を追加」で確定し、もう一方の関節や別の時刻の調整を重ねます。「最後の調整を取消」で戻せます。
5. 新しい名前を指定し「プレビューの内容を別データセットに保存」を押します。未確定の入力中の調整も含めて保存します。

調整は `Δθ(t) = amplitude × exp(-0.5 × ((t-center)/sigma)²)`。元フレームの `frame_index / fps` を時間軸とし、再サンプリングや再生速度変更は行いません。ガウス関数の裾はエピソード全体にかかり、端点でゼロには固定しません。角度は既存可視化のIloha座標で指定し、保存時に元の座標系の符号へ変換します。

デフォルトでは `action` のみ変更します。`observation.state` のチェックを入れると、元の状態値にも同じ差分を加算します。状態をactionの値で置き換える処理ではありません。画像などの記録内容はそのまま複製します。

保存先は `datasets/<新しい名前>`。全エピソードとメタデータを複製し、選択エピソードの対象関節だけを編集します。対象特徴量の全体・エピソード別統計（分位点を含む）を再計算し、`meta/joint_edits.json` に元データセット名と編集内容を記録します。元データと既存保存先は上書きしません。保存後のデータセットは既存の軌道接続ページで一覧を更新して使用できます。

可視化は `iloha_trajectory_web.py` のリンクモデルを共有しています。関節制限・衝突判定・自動的な距離最適化は行いません。
